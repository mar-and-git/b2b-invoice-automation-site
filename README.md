# B2B Invoice Automation — Public Information Site

This repository hosts **public application information only** for B2B Invoice Automation, a privately operated Windows financial-document workflow application.

- [Home](https://mar-and-git.github.io/b2b-invoice-automation-site/)

## Scope and safety

This website explains the app's intended Gmail read-only financial-document integration and describes privacy and data-handling practices. The repo contains **no application source code, OAuth client secrets, tokens, invoices, personal accounting records or confidential operational files**.

## Publish on GitHub Pages

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, set **Source = Deploy from a branch**.
3. Set **Branch = main** and **Folder = / (root)**, then **Save**.
4. Wait for GitHub to show the published site URL and verify that both links above open successfully using HTTPS.

**Important:** The public GitHub Pages URL and repository creation do not, by themselves, prove that Google OAuth accepts or verifies the `github.io` domain. Verify Google's requirements and ownership independently before setting Google Auth Platform Branding URLs or changing the audience publishing status. Do not falsely claim Google OAuth verification.
